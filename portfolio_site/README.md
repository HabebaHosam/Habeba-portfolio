# Habeba Hossam — Data Analyst Portfolio

A responsive, static portfolio website created from the content in the supplied portfolio PDF.

## Preview locally
1. Extract the ZIP file if you downloaded it.
2. Open `index.html` in a browser. Internet access is needed for the Google Fonts; the rest of the site is local.

## Host it free with Netlify (easiest)
1. Go to https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the **portfolio_site** folder (or the extracted folder contents) onto the deploy area.
4. Netlify will publish the site and provide a public URL. You can change the site name in the site settings.

## Host it free with GitHub Pages
1. Create a new public repository on https://github.com/new (for example `habeba-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. Your site URL will appear in the Pages settings, typically `https://YOUR-USERNAME.github.io/habeba-portfolio/`.

## Before publishing
- Verify the phone number and LinkedIn URL in `index.html`.
- The PDF project pages are used as temporary project previews. For a stronger portfolio, replace `assets/page-07.jpg`, `assets/page-09.jpg`, and `assets/page-10.jpg` with clean dashboard screenshots.
- Add links to live dashboards or downloadable project files if you want visitors to explore the work in more detail.
- To update wording or contact details, edit `index.html`. To change colors and spacing, edit the variables at the top of `style.css`.
